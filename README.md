A react application to generate random NFL teams

This project was originally built for picking user teams in Madden, but it may also
be useful for other things as well

### Career Rules Input

Users can choose from the following rules to create a baseline career context:

- Position

- Draft Profile

- Whether a team is chosen, or whether a draft position is chosen.
    This is for a franchise simulation, so draft position means that whatever team is picking at
    round X pick Y, that is the team chosen.

### Career Context

Based on the rules requested by the user, career context have the following attributes:

- Position

- Team (or draft pick #)

- Starting OVR

- Starting Dev Trait

- Basic career story
